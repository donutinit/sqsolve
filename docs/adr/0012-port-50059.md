# ADR 0012. Collaboration port

**Status:** Accepted, pending PoC-07.

**Context.** Studio Server publishes 50059 as "collaboration chat". Blackmagic support
describes 50059 to 50314 as the link between clients since Resolve 15.2 [01 §9].

**Decision.** The server publishes only 5432 and the panel. The documentation for editors
explains opening 50059 to 50314 between workstations.

**Alternatives.** Publishing 50059 "just in case": it has no effect according to the evidence and
confuses troubleshooting.

**Consequences.** If PoC-07 shows collaboration traffic towards the server, this ADR is
superseded and which service would receive it is evaluated.
