# ADR 0012. Puerto de colaboración

**Estado:** Aceptado, pendiente de PoC-07.

**Contexto.** Studio Server publica 50059 como "chat de colaboración". El soporte de Blackmagic
describe 50059 a 50314 como el enlace entre clientes desde Resolve 15.2 [01 §9].

**Decisión.** El servidor publica solo 5432 y el panel. La documentación para editores explica
abrir 50059 a 50314 entre estaciones.

**Alternativas.** Publicar 50059 "por si acaso": no tiene efecto según la evidencia y confunde el
diagnóstico.

**Consecuencias.** Si PoC-07 muestra tráfico de colaboración hacia el servidor, este ADR se
reemplaza y se evalúa qué servicio lo recibiría.
