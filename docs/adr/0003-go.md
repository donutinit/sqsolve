# ADR 0003. Backend language

**Status:** Accepted (2026-10-18).

**Context.** The service manages external processes, long cancellable jobs, HTTP, TLS and
cryptography; it must be small, reproducible and easy to maintain for years.

**Decision.** Go, `CGO_ENABLED=0`, standard library for HTTP, templates, TLS and logging; closed
list of dependencies in `06-stack.md` §9.

**Alternatives.** Python, TypeScript with Node, Rust (`06-stack.md` §1).

**Consequences.** Static binary for amd64 and arm64; the same piece serves as server, CLI and
`init`. The domain model is kept simple on purpose.
