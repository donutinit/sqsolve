# ADR 0003. Lenguaje del backend

**Estado:** Aceptado (2026-10-18).

**Contexto.** El servicio gestiona procesos externos, tareas largas cancelables, HTTP, TLS y
criptografía; debe ser pequeño, reproducible y fácil de mantener años.

**Decisión.** Go, `CGO_ENABLED=0`, biblioteca estándar para HTTP, plantillas, TLS y registros;
lista cerrada de dependencias en `06-stack.md` §9.

**Alternativas.** Python, TypeScript con Node, Rust (`06-stack.md` §1).

**Consecuencias.** Binario estático para amd64 y arm64; la misma pieza sirve de servidor, CLI e
`init`. El modelo de dominio se mantiene simple a propósito.
