Save the recovery kit

The kit contains the master key that encrypts the library passwords. If this server is lost, the kit and the copy of the backups recover everything, including the passwords workstations already use.

  • Keep it outside this server (password manager, a USB stick in a drawer).
  • Treat it like a password: whoever has it together with the volumes can read the credentials.
