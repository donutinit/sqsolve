Connect {{$c.LibraryName}} in DaVinci Resolve

  1. Open DaVinci Resolve. In the Project Manager, open the list of project libraries.
  2. Add a network library (PostgreSQL) and choose Connect.
  3. Enter these values:
    Library name
    {{$c.Database}}
    Location
    {{or $c.Host "To be confirmed"}}
    Username
    {{$c.User}}
    Password
    the administrator provides it through a private channel
  4. Open the library and create or open a project.

If something fails

  • The workstation must be on the same network as the server or connected through the studio VPN.
  • The server uses port 5432. Resolve does not ask for the port.
  • To collaborate, all workstations need Resolve Studio in the same version and TCP ports 50059 to 50314 open between them.
