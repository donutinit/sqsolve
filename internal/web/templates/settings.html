Manual jobs

{{if $p.Can "settings.edit"}}

Verify the latest backups

Test restore of the most recent backup of each library.

{{template "csrf" .CSRF}}

Apply retention

Deletes expired backups according to each library's policy; never the pinned ones.

{{template "csrf" .CSRF}}

Optimize libraries

VACUUM ANALYZE on each database, like "Optimize" in Resolve, without reindexing.

{{template "csrf" .CSRF}}

Back up the control plane

Copies the sqsolve database (users, catalog, audit log) to the backups volume.

{{template "csrf" .CSRF}}

Check the catalog

Compares the catalog with the files on the volume and marks the missing ones.

{{template "csrf" .CSRF}}

Rebuild the catalog

Reads the manifests on the backups volume again and rebuilds the catalog.

{{template "csrf" .CSRF}}

Regenerate pg_hba.conf

Rewrites the PostgreSQL access rules from the catalog and reloads them.

Upgrade DaVinci Resolve

Opening projects in a newer Resolve version can make them inaccessible in the older one. Before upgrading the workstations, sqsolve backs up and verifies all libraries with a test restore.
