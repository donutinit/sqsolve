Welcome to sqsolve

Create the administrator account and tell us how the DaVinci Resolve workstations will reach this server.

1. Installation code

It is printed in the output of the sqsolve container (on a NAS, in the app logs). It only works until the first administrator exists.

2. Administrator

At least 12 characters. A phrase of several words works well.

3. Network

The IP or server name as typed in the Resolve location field, without a port. We suggest the address you used to open this panel.

4. Default backups
