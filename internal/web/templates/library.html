Collaboration between workstations
  • Resolve collaboration requires DaVinci Resolve Studio on all workstations and the same Resolve version.
  • Workstations talk to each other over TCP on ports 50059 to 50314: open them in each workstation's firewall. The server only needs 5432.
  • Connecting the library does not prove that the link between workstations works: if chat or locks do not update, check those ports.
Access key .resolvedbkey

Resolve can import .resolvedbkey keys generated by the official Project Server. Its format is not documented; sqsolve does not generate them until that is verified (PoC-05). Use the values above.
